## ⚠️ Ek Remaining Performance Issue — Abhi Bhi Baaki

### `realPdfUtils.ts` mein `getPdfjsLib` top-level import hai 🟠

```ts
// Line 11 — yeh abhi bhi top-level import hai:
import { getPdfjsLib } from './pdfjs-loader';
```

**Good news:** `getPdfjsLib()` function ke andar call ho rahi hai — module load hone pe pdfjs download **nahi** hota. Lekin import itself `pdfjs-loader.ts` ko module graph mein kheenchta hai, toh Vite dono ko ek hi chunk mein bundlekarta hai. Iska matlab `realPdfUtils` chunk thoda bada hai — practical impact **low** hai.

**Actual fix:** Top-level import hata do, dynamic import karo:
```ts
// Har async function ke andar locally:
const { getPdfjsLib } = await import('./pdfjs-loader');
```
Lekin yeh 2034 line file mein ~10 jagah change hai — agar time ho toh karo, warna skip bhi kar sakte ho.

### 1. Hover Prefetch — Tool Pages 🟠
**Sabse bada remaining win.** Jab user Home pe tool card pe hover karta hai, tab page chunk preload ho sakta hai. Jab tak click karta hai, chunk already download ho chuka hota hai — **instant navigation**.

`App.tsx` mein yeh add karo:
```tsx
// wouter ka Link component extend karo
<Link 
  href="/merge-pdf"
  onMouseEnter={() => import("@/pages/MergePDF")} // prefetch on hover
>
```

### 2. Rate Limiting — Server pe nahi hai 🔴
`/api/compress-pdf`, `/api/pdf/lock` etc. pe koi rate limiting nahi. Koi bhi bot teri Replit server crush kar sakta hai. Replit mein:
```bash
npm install express-rate-limit
```
Phir `server/routes.ts` ke top pe:
```ts
import rateLimit from 'express-rate-limit';
const limiter = rateLimit({ windowMs: 60_000, max: 20 }); // 20 req/min per IP
app.use('/api/', limiter);
```

### 3. `@dnd-kit` vendor chunk missing hai 🟡
`vite.config.ts` mein `@dnd-kit` ka chunk nahi hai. `ImagesToPDF` aur `PNGToPDF` drag-drop use karte hain. Add karo:
```ts
if (id.includes("@dnd-kit")) return "dnd-vendor";
```
